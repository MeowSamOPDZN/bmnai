# bmnai

Booman 4.2 — AI chat UI replica, built from reference mockups.

- `index.html` — app shell: sidebar, hero/new-chat view, chat view, composers
- `styles.css` — section-by-section styles: tokens, shell, topbar, sidebar, hero, chat, responsive breakpoints, animations
- `app.js` — view flow, mobile drawer, animated send sequence, copy-table, reactions
- `avatar.png` — sidebar user avatar

Live: https://bmnai.vercel.app
